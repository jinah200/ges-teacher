[심화] 업무 자동화 로봇 만들기

선택 모듈입니다. 코드 붙여넣기와 트리거 설정이 필요해 처음에는 어려울 수 있어요. 모듈 1~5를 마치고 시간이 남거나, 자동화에 관심 있는 분만 따라오세요. 건너뛰어도 연수 흐름에는 지장이 없습니다.

폼에 제출이 들어오면 — 아무도 건드리지 않아도 — 맞춤 결과물이 만들어져 메일로 발송됩니다. Apps Script 트리거로 사람 없이 돌아가는 자동화를 만듭니다.

역량 — 교사 업무 효율·전문성 (반복을 시스템으로)

무엇을 자동화하나요?

초등 활동 소감을 받으면 추억 엽서(이름·소감·사진)를 자동으로 만들어 가정으로 발송.

중등 과제 제출을 받으면 개별 확인·피드백 안내 메일을 자동 발송.

고등 응모·제출을 받으면 고유 번호 부여 + 확인증(PDF)을 자동 발송.

모듈 5에서 만난 Apps Script, 기억나죠? 그땐 데이터를 '읽어 내보내는(API)' 용도였고, 이번엔 폼 제출에 반응해 일하는 트리거 용도예요 — 같은 도구, 다른 초능력.

자동화 흐름

1

구글 폼

이름·소감·사진·이메일 제출

2

트리거 발동

onFormSubmit 실행 → Apps Script 시작, 행 번호로 고유번호 부여

3

슬라이드 복사·치환

템플릿의 {{이름}}·{{소감}}·{{응모번호}} 치환, '사진자리' 도형을 업로드 사진으로 교체

4

PDF 변환·메일 발송

완성본을 PDF로 바꿔 신청자 이메일로 자동 발송

🧭 맥락 TIP 자동화 프롬프트에는 폼 질문 제목, 슬라이드 표식, 시트 열 이름처럼 "내 파일의 실제 이름"을 그대로 알려 주세요. AI는 내 파일을 볼 수 없어서, 이름이 하나라도 다르면 코드가 동작하지 않습니다.

실습 ① · AI로 코드 받기

아래 프롬프트를 Gemini에 붙여넣으면 거의 완성된 Apps Script 코드를 만들어 줍니다.

구글 폼이 제출되면 슬라이드 템플릿을 복사해 {{이름}}과 {{소감}} 항목을 채우고, 대체 텍스트(제목 또는 설명)가 '사진자리'인 도형을 사용자가 업로드한 사진 파일로 바꾼 뒤, PDF로 변환하여 신청자에게 메일로 자동 발송하는 Apps Script를 만들어줘.

[필수 조건]
1. 구글 시트에 데이터가 들어오는 순서대로 고유한 세 자리 응모번호(예: 001, 002...)를 코드가 스스로 계산해서 자동 생성하게 해줘. 동시에 여러 명이 제출해도 번호가 겹치지 않도록 e.range.getRow()를 사용해줘.
2. 그 응모번호를 슬라이드의 {{응모번호}} 자리에 치환해줘.
3. 구글 폼 질문 명칭은 이메일, 이름, 소감, 사진이며, TEMPLATE_ID와 FOLDER_ID는 코드 상단 전역 변수로 분리해줘.

실습 ② · 완성 코드 (바로 사용)

시간이 부족하면 아래 완성 코드를 Apps Script에 붙여넣고, 상단 두 값만 교체한 뒤 트리거(onFormSubmit · 양식 제출 시)를 설정하세요.

// MT/활동 추억 엽서 + 응모번호 자동 발송 시스템
// [사용 전 필수] 아래 두 값을 본인 것으로 교체
const TEMPLATE_ID = 'YOUR_TEMPLATE_SLIDE_ID';
const FOLDER_ID   = 'YOUR_OUTPUT_FOLDER_ID';

function onFormSubmit(e) {
  // 1. 응모번호 생성 (동시 제출 안전)
  const row      = e.range.getRow();
  const entryNum = String(row - 1).padStart(3, '0');

  // 2. 폼 응답 추출 (질문명이 폼과 정확히 일치해야 함)
  const responses = e.namedValues;
  const email     = responses['이메일'][0].trim();
  const name      = responses['이름'][0].trim();
  const memory    = responses['소감'][0].trim();
  const photoUrls = responses['사진'];

  // 3. 슬라이드 템플릿 복사
  const templateFile = DriveApp.getFileById(TEMPLATE_ID);
  const outputFolder = DriveApp.getFolderById(FOLDER_ID);
  const copiedFile   = templateFile.makeCopy(`추억엽서_${name}_${entryNum}`, outputFolder);
  const presentation = SlidesApp.openById(copiedFile.getId());
  const slide        = presentation.getSlides()[0];

  // 4. 텍스트 치환
  presentation.replaceAllText('{{이름}}',    name);
  presentation.replaceAllText('{{소감}}',    memory);
  presentation.replaceAllText('{{응모번호}}', `#${entryNum}`);

  // 5. 사진 치환 (대체 텍스트 '사진자리' 도형을 이미지로)
  if (photoUrls && photoUrls[0] && photoUrls[0].trim() !== '') {
    try {
      const photoUrl     = photoUrls[0].trim();
      const photoIdMatch = photoUrl.match(/id=([a-zA-Z0-9_-]+)/) ||
                           photoUrl.match(/\/d\/([a-zA-Z0-9_-]+)/);
      const photoBlob    = DriveApp.getFileById(photoIdMatch[1]).getBlob();
      const elements     = slide.getPageElements();
      for (const el of elements) {
        if (el.getTitle() === '사진자리' || el.getDescription() === '사진자리') {
          const type = el.getPageElementType();
          if (type === SlidesApp.PageElementType.SHAPE)
            el.asShape().replaceWithImage(photoBlob);
          else if (type === SlidesApp.PageElementType.IMAGE)
            el.asImage().replace(photoBlob, true);
          break;
        }
      }
    } catch (err) {
      console.error('사진 로드 실패:', err.message);
    }
  }
  presentation.saveAndClose();

  // 6. PDF 변환 및 메일 발송
  const pdfBlob = DriveApp.getFileById(copiedFile.getId())
    .getAs('application/pdf')
    .setName(`추억엽서_${name}_${entryNum}.pdf`);

  GmailApp.sendEmail(email,
    `[추억 엽서] ${name}님의 응모번호: #${entryNum}`,
    `${name}님, 추억 엽서를 보내드립니다!\n\n응모번호: #${entryNum}\n\n첨부파일을 확인해 주세요.`,
    { attachments: [pdfBlob] }
  );
}
핵심 ① 폼 질문 이름(이메일·이름·소감·사진) ② 슬라이드 표식({{이름}}·{{소감}}·{{응모번호}}·대체 텍스트 '사진자리') ③ 트리거 설정(onFormSubmit) — 이 세 가지만 맞으면 작동합니다.
보안 권한 첫 실행 때 구글 권한 승인이 뜹니다. 본인 계정으로 승인해야 메일 발송·드라이브 접근이 됩니다.
💡 TIP 사본으로 먼저 — 원본 폼·슬라이드를 복사해 두고, 사본에서 시험하세요.
💡 TIP 내 메일로 먼저 — 처음 테스트 제출은 내 메일 주소로 해서 발송 내용을 확인하세요.
💡 TIP 오류는 그대로 붙여넣기 — 빨간 오류 메시지를 복사해 AI에게 "이 오류를 고쳐 줘"라고 하면 대부분 해결됩니다.
💡 TIP 개인정보 — 학생·학부모에게 메일을 보내는 자동화는 학교의 개인정보·정보보안 지침을 먼저 확인하세요.
