📊 STEP 2 · Canvas 대시보드

STEP 1에서 모은 교사 고민 설문 응답을 Gemini Canvas 대시보드로 만들어, 우리 연수장의 고민을 한눈에 봅니다. 이 대시보드 결과가 바로 다음 STEP 3 Notebook 정리의 재료가 됩니다. 방법은 두 갈래 — 쉬운 길(코드 없이 붙여넣기)과 실시간 길(Apps Script) — 입니다.

역량 — 데이터 기반 교수·학습 설계
🧭 함께 보기 연수장에서는 모듈 2-A 교사 고민 설문 응답을 대시보드로 띄워 "우리 연수장 선생님들의 고민 지도"를 함께 봅니다. 서술형 응답은 Gemini에 "주제별로 묶고 대표 응답을 2개씩 보여 줘"라고 요청해 보세요.

학교급별 목표

초등 대시보드 체험까지 — 강사 데모로 '데이터로 보면 결정이 달라진다'를 경험.

중등 대시보드 직접 제작 — 내 진단 시트로 API를 만들고 차트를 띄웁니다.

고등 심화 — 필터·검색·학생별 상세까지 붙여 개별 지도에 활용.

🧭 맥락 TIP 대시보드는 데이터 맥락이 핵심입니다. 시트의 열 이름과 응답 예시 2~3줄을 함께 붙여 주세요. AI는 내 시트를 볼 수 없어서, 열 이름을 알려 줘야 정확한 코드와 차트를 만듭니다.
쉬운 길 · 추천 · 코드 없음 📋 붙여넣기 대시보드 응답 시트를 복사해 Canvas에 붙여넣으면 5분 만에 완성. 연수장에서 함께 쓰기 좋아요.
실시간 길 · 심화 🔄 Apps Script 대시보드 데이터 창구(API)를 만들어 응답이 들어올 때마다 자동 갱신. 중·고등/심화용.

쉬운 길 · 붙여넣기 대시보드 추천

코드가 필요 없습니다. 구글 폼 → 응답 → 스프레드시트에서 응답 표를 복사해, 아래 '데이터' 칸에 붙여넣으세요. 완성된 프롬프트를 Gemini 우측 Canvas에 붙여넣으면 대시보드가 만들어집니다.

💡 TIP 연수장 전체용 대시보드는 강사가 미리 하나 만들어 띄워 두면 진행이 매끄럽습니다. 응답이 늘면 데이터만 다시 붙여넣어 새로 그리면 됩니다.
💡 TIP 서술형(교육의 본질·풀고 싶은 BUG)이 많으면 "주제별로 묶어 대표 응답 2개씩"을 켜세요. 다음 STEP 3 Notebook에서 이 묶음이 그대로 소스가 됩니다.

실시간 길 · Apps Script 대시보드 심화

응답이 들어올 때마다 자동으로 갱신되는 대시보드입니다. 코드 붙여넣기와 배포가 필요하니, 익숙하신 분이나 중·고등 실습에서 하세요.

3단계

1

진단 응답 시트 열기

STEP 1에서 만든 설문(또는 학생 진단) 폼의 응답 시트를 엽니다. (폼 → 응답 → 스프레드시트로 연결)

2

Apps Script로 데이터 창구(JSON API) 만들기

시트 상단 확장 프로그램 → Apps Script에서 아래 코드를 붙여넣고, 배포 → 새 배포 → 웹 앱(액세스: 모든 사용자)으로 배포합니다. 배포 후 나오는 웹 앱 URL을 복사해 두세요.

3

Gemini Canvas로 대시보드 빌드하기

Gemini 채팅에서 Canvas를 열고 아래를 붙여넣습니다. [웹 앱 URL]에 2단계에서 복사한 주소를 넣으세요.

심화 · 학생별 상세 붙이기 고등

TIP 결과가 예상과 다르면 "장소/항목이 안 보여", "이렇게 바꿔줘"처럼 대화로 고쳐 나가면 됩니다. 디버깅도 AI와 함께 하는 과정이에요.
💡 TIP 한 단계씩 확인하며 진행하세요. 1단계가 되는지 보고 나서 2단계로 넘어가면 오류 찾기가 쉽습니다.
💡 TIP 오류 메시지는 그대로 복사해 AI에게 붙여넣으세요.
💡 TIP 학생 이름 대신 번호나 가명으로 보이게 하고, 민감 항목은 대시보드에서 빼세요.
💡 TIP 공개 범위 최소화 — 링크를 아는 사람이 볼 수 있으니 필요한 사람에게만 공유하세요.
💡 TIP 차트는 결정을 위해 — 예쁜 차트보다 "이 결과로 무엇을 바꿀지"를 먼저 정하고 만드세요.
